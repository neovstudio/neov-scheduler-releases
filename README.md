# NEOV 스케줄러 설치 파일

NEOV STUDIO 마감 위젯 앱의 설치 파일과 자동 업데이트(latest.json)만 올리는 저장소예요. 소스는 비공개 저장소에 있어요.

최신 버전: [Releases](https://github.com/neovstudio/neov-scheduler-releases/releases/latest)

| 운영체제 | 파일 |
|---|---|
| Windows | `NEOV-Scheduler_<버전>_x64-setup.exe` |
| macOS | `NEOV-Scheduler_<버전>_universal.dmg` |
